## Summary
Azure's network foundation services—Virtual Network, Private Link, and DNS—provide secure, private connectivity and DNS resolution for Azure resources. They form an integrated stack where Virtual Network enables isolated networks, Private Link secures private endpoint access, and DNS handles public/private name resolution with hybrid scenarios.

## Key Points
- Azure Virtual Network creates private cloud networks, supporting hub-spoke topologies for resource segmentation and on-premises connectivity.
- Azure Private Link enables secure private endpoints for services without public internet exposure, with DNS integration options for resolution.
- Azure DNS includes Public DNS, Private DNS zones, Private Resolver (for hybrid DNS resolution), and Traffic Manager (for global load balancing).
