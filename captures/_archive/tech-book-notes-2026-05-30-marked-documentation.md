# Marked Documentation
Source: https://marked.js.org/
Captured: 2026-05-30 | Action: reference-only

## Summary
Marked is a high-performance, lightweight Markdown compiler supporting Markdown 1.0 (100%), CommonMark (98%), and GitHub Flavored Markdown (97%) with strict compliance. It requires manual HTML sanitization to prevent XSS vulnerabilities and is compatible with CLI, browser, and Node.js environments.

## Key Points
- High-speed, low-level compiler with strict compliance to Markdown specs
- Requires manual HTML sanitization (XSS risk) using tools like DOMPurify
- Supports multiple Markdown flavors with near-complete feature coverage
- CLI, browser, and Node.js integration options
