## Summary
pytest is a Python testing framework enabling simple, readable tests via plain assert statements with detailed failure introspection. It features auto-discovery of test cases, modular fixtures for resource management, and compatibility with unittest test suites, supported by a 20-minute onboarding guide.

## Key Points
- Plain assert statements with detailed failure messages (no self.assert* required)
- Auto-discovery of test modules/functions
- Modular fixtures for test resource management
- Compatibility with unittest test suites
- Extensive plugin ecosystem (1300+ plugins)
