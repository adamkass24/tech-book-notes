# Uvicorn
Source: https://uvicorn.dev/
Captured: 2026-05-30 | Action: reference-only

## Summary
Uvicorn is a high-performance ASGI server for Python, enabling asynchronous web applications with HTTP/1.1 and WebSocket support. It provides a minimal interface for async frameworks and simplifies deployment via command-line or programmatic configuration.

## Key Points
- ASGI server implementation for Python async frameworks
- Supports HTTP/1.1 and WebSockets with configurable protocol options
- Quickstart example with minimal ASGI app and `uvicorn.run()`
- Gunicorn worker class for production deployment with process management
