## Summary
Azure Virtual Network (VNet) is the foundational service for creating private, secure networks in Azure, enabling communication between VMs, internet, on-premises resources, and Azure services. It supports key scenarios like traffic filtering, routing, and integration via service endpoints or Private Link, with no cost for the VNet itself.

## Key Points
- Core networking foundation for private Azure environments, enabling secure resource communication (internal, internet, on-premises).
- Key features: service endpoints, virtual network peering, NSG-based traffic filtering, custom routing via route tables/BGP.
- Free service; costs apply to deployed resources (VMs, etc.) and integration methods (e.g., ExpressRoute).
- Integrates with Azure services via Private Link, service endpoints, or dedicated deployments.
